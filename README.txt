IAN ONGERA — ICT PORTFOLIO
===========================

Files
- index.html: page structure and portfolio content
- style.css: responsive dark-blue portfolio styling
- script.js: mobile navigation, reveal animations, copy-email button

Preview locally
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For development, open the folder in VS Code and use Live Server if available.

Deploy to HostPinnacle/cPanel
1. Open cPanel File Manager.
2. Open public_html (or the folder for your chosen domain/subdomain).
3. Upload the files inside this folder, keeping index.html, style.css and script.js together.
4. Visit your domain and confirm the site loads.

Before publishing
- Confirm the email address and all profile details.
- Add your own headshot if you want one; the current hero uses a designed monogram rather than a stock portrait.
- Add GitHub/LinkedIn links if you want them displayed.
- If you want a CV download button, upload your final CV PDF and link it from the page.
- Project artwork is illustrative and not represented as real product screenshots.
- The Google Fonts import requires an internet connection; the page falls back to generic sans-serif fonts if unavailable.

Built with HTML, CSS and vanilla JavaScript. No PHP, database, framework, or build step required.
